How allowances work

Task and project allowances are percentages of each provider's current quota window. Account movement during a run is charged conservatively to that task, including other usage on the same account. This is an estimate, not provider-reported task usage.

Backfill checks fresh account readings, protects your reserve, and stops active work when the allowance is reached. A request already in flight can overshoot. Interrupted work is saved. Native permissions remain in effect.

One background task runs at a time. Approving a result marks it reviewed; it does not publish or deploy anything.
